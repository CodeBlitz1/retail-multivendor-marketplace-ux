# Information Architecture (IA)

## 1. Overview

The Information Architecture defines how content and features are organized within the Multi-Vendor Marketplace App.

Its purpose is to make navigation intuitive and help shoppers find products efficiently.

## 2. Navigation Hierarchy

* **Home**

  * Search
  * Hero banners
  * Top vendors
  * Daily Deals

* **Categories**

  * Category tree
  * Product grid
  * Filters and sort
  * Search reasults

* **Vendors**

  * All vendors
  * Vendors store
  * Follow vendor
  * Ratings

* **Cart**

  * Cart by vendor
  * Address
  * Payment
  * Order placed

* **Account**

  * My orders
  * Wishlist
  * Addresses
  * Help and returns

## 3. Design Rationale

The structure groups related information into recognizable sections.

Search and category navigation support product discovery, while the Product Detail Page provides the information needed to evaluate a product before adding it to the cart.

The Cart groups selected products and provides a clear next step toward checkout.
